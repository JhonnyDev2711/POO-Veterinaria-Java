REGISTRO BÁSICO DE PERROS - POO EN JAVA

Este proyecto es una práctica sencilla de Programación Orientada a Objetos.
La idea es registrar dos perros de ejemplo y probar algunas acciones desde la consola.

ARCHIVOS:
- src/Perro.java: aquí está la clase Perro, sus atributos, el constructor y sus métodos.
- src/Main.java: aquí se crean los objetos y se prueban los métodos.

CONCEPTOS QUE SE PRACTICAN:
- Clase: Perro, que sirve como molde.
- Atributos: nombre, raza y edad.
- Constructor: recibe los datos iniciales del perro.
- Objetos: perro1 y perro2, creados con new.
- Métodos: mostrarFicha(), ladrar() y cumplirAnios().
- Encapsulamiento inicial: los atributos están declarados como private.

CÓMO EJECUTAR:
Se necesita tener instalado un JDK de Java para poder ejecutar el código.

RESULTADO ESPERADO:
El programa muestra la ficha de Max y Luna, simula sus ladridos y aumenta la edad de Max de 3 a 4 años.
